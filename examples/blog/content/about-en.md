# About

This is a demo site built with **XFM**, showcasing themes, plugins and Markdown support.
It is the English translation of the [中文版本](/about/) — both pages share the same
`translationKey: about`, so the SEO plugin cross-links them with `hreflang` and the
language switcher appears in the nav.

## Stack

- Zero runtime dependencies: the output is plain HTML + CSS
- Parallel rendering with worker threads at build time
- Themes customized with a 30-line template syntax
