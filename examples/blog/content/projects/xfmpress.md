# xfmpress

本站就是用 xfmpress 构建的。这个页面属于 `projects` 自定义集合：
它出现在 [作品列表](/projects/)，但不会混进首页文章流和 RSS。

- 仓库：[xfm0797/xfm](https://github.com/xfm0797/xfm)
- 安装：`npm i -g xfmpress`
- 上手：`xfm create my-blog --template=blog && xfm dev my-blog`
